# CPX-HT16K33
HT16K33 Alphanumeric Display Circuit Playground Express MakeCode Extension Package
> PXT/adafruit

## Adafruit Quad Alphanumeric HT16K33 Extension for MakeCode CPX
Custom MakeCode extension for controlling the Adafruit Quad 14-Segment Alphanumeric Backpack with STEMMA QT over I2C.

## Supported Blocks
- **Initialize Alphanumeric Display at address [112]**
- **Show String [text]**
- **Show Number [number]**
- **Set Shift Interval [ms]**
- **Set Blink Rate [rate]**
- **Set Brightness [level]**
